Explain the process of mining the colossal patterns with pattern fusion method 
with suitable example. 
Definition 
 
Colossal Frequent Patterns are very large frequent itemsets that contain a large 
number of items and appear frequently in a transaction database. Instead of 
generating all frequent itemsets (which can be exponentially many), Pattern 
Fusion directly constructs large (colossal) patterns by merging smaller 
frequent patterns. 
 
Pattern Fusion is an efficient approach because it avoids generating all subsets 
of a frequent itemset, thereby reducing computational complexity and 
memory usage. 
 
Need for Pattern Fusion 
 
Traditional algorithms like Apriori and FP-Growth generate a huge number of 
frequent itemsets before finding the largest ones. 
 
For example, 
 
Frequent Patterns 
 
A 
B 
C 
AB

ABCDE 
 
If the final objective is to obtain only ABCDE, generating all intermediate 
patterns is inefficient.

iv. Tree Pruning 
Definition 
Tree Pruning is the process of removing unnecessary branches from a 
decision tree to reduce overfitting and improve the model's ability to generalize to 
unseen data. 
Types of Pruning 
1. Pre-Pruning (Early Stopping) 
The tree construction is stopped early based on conditions such as: 
• 
Maximum tree depth  
• 
Minimum number of samples per node  
• 
Minimum information gain  
Example 
          Age 
         /   \ 
      Young  Adult 
        | 
      Student 
        | 
      Pass 
The algorithm stops expanding the tree once a stopping criterion is met. 
 
2. Post-Pruning 
First, a complete tree is built. Then branches that do not improve prediction 
accuracy are removed. 
Example 
Before Pruning 
            Age 
           /    \ 
      Young     Adult 
      /   \       \ 
   Student Non-Student Pass 
    /   \ 
 Pass  Pass 
After Pruning 
          Age 
         /    \ 
      Young   Adult 
        |       | 
      Pass    Pass 
The unnecessary "Student" split is removed because it does not improve 
classification. 
Advantages of Tree Pruning 
• 
Reduces overfitting  
• 
Improves prediction accuracy  
• 
Produces simpler and more interpretable trees
