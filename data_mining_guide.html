Unit · Correlation Analysis

1 — Chi-Square Test of Independence

Used during the data integration phase to check whether two categorical (nominal) attributes are correlated. If they are strongly related, one attribute is redundant and can be dropped.

The hypotheses

  • \(H_0\) (null hypothesis): the two attributes are independent (not correlated).
  • \(H_a\) (alternate hypothesis): the two attributes are dependent (correlated).

Formulas

Chi-square statistic — if A has \(c\) values and B has \(r\) values $$\chi^2=\sum_{i=1}^{c}\sum_{j=1}^{r}\frac{(o_{ij}-e_{ij})^2}{e_{ij}}$$ Expected count for a cell $$e_{ij}=\frac{\text{Count}(A=a_i)\times \text{Count}(B=b_j)}{n}=\frac{(\text{row total})\times(\text{column total})}{\text{grand total}}$$ Degrees of freedom $$df=(c-1)(r-1)$$

Here \(o_{ij}\) is the observed count and \(e_{ij}\) is the expected count (what you'd see if the attributes were truly independent), and \(n\) is the total number of observations.

Numerical · 1500 people surveyed

Gender (M/F) was recorded against preferred reading material (Fiction / Non-fiction). The observed table:

Observed \(o_{ij}\)MaleFemaleRow total
Fiction250200450
Non-fiction5010001050

Step 1 · Expected counts

$$e_{\text{Fic,M}}=\frac{450\times300}{1500}=90 \qquad e_{\text{Fic,F}}=\frac{450\times1200}{1500}=360$$

$$e_{\text{Non,M}}=\frac{1050\times300}{1500}=210 \qquad e_{\text{Non,F}}=\frac{1050\times1200}{1500}=840$$

Step 2 · Apply the chi-square formula

$$\chi^2=\frac{(250-90)^2}{90}+\frac{(200-360)^2}{360}+\frac{(50-210)^2}{210}+\frac{(1000-840)^2}{840}$$

Each squared difference is \(160^2=25600\):

$$\chi^2=\frac{25600}{90}+\frac{25600}{360}+\frac{25600}{210}+\frac{25600}{840}$$

$$\chi^2=284.44+71.11+121.90+30.48=\mathbf{507.93}$$

Step 3 · Compare with the critical value

\(df=(2-1)(2-1)=1\). The critical value at significance \(\alpha=0.05\) for \(df=1\) is 3.841.

Since \(507.93 \gg 3.841\), we reject \(H_0\).

Conclusion Gender and preferred reading material are strongly dependent (correlated). The very large \(\chi^2\) value signals that knowing someone's gender tells you a lot about their reading preference — so in data integration these two attributes carry overlapping information.

2 — Pearson Correlation Coefficient

The numeric-data counterpart of the chi-square test. Used in the data integration phase to detect redundancy between two numeric attributes.

Formulas

Pearson coefficient $$r=\frac{\text{Cov}(x,y)}{\sigma_x\,\sigma_y}$$ Covariance $$\text{Cov}(x,y)=\frac1n\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y)$$ Standard deviations $$\sigma_x=\sqrt{\tfrac1n\sum(x_i-\bar x)^2}\qquad \sigma_y=\sqrt{\tfrac1n\sum(y_i-\bar y)^2}$$
How to read \(r\) \(r=+1\) → perfect positive correlation (as \(x\) rises, \(y\) rises). \(r=-1\) → perfect negative. \(r\approx 0\) → no linear relationship. The closer \(|r|\) is to 1, the more redundant the two attributes are, so one can be removed during feature selection / data reduction.

Step 1 · Means

$$\bar x=\frac{1+2+3+4+5}{5}=3 \qquad \bar y=\frac{2+4+6+8+10}{5}=6$$

Step 2 · Covariance

$$\text{Cov}(x,y)=\frac15\big[(-2)(-4)+(-1)(-2)+(0)(0)+(1)(2)+(2)(4)\big]$$

$$=\frac15(8+2+0+2+8)=\frac{20}{5}=4$$

Step 3 · Standard deviations

$$\sigma_x=\sqrt{\tfrac15\big[(-2)^2+(-1)^2+0^2+1^2+2^2\big]}=\sqrt{\tfrac{10}{5}}=\sqrt2=1.41$$

$$\sigma_y=\sqrt{\tfrac15\big[(-4)^2+(-2)^2+0^2+2^2+4^2\big]}=\sqrt{\tfrac{40}{5}}=\sqrt8=2.82$$

Step 4 · Pearson coefficient

$$r=\frac{4}{1.41\times2.82}=\frac{4}{3.976}\approx \mathbf{1.00}$$

Conclusion \(r=1\) → perfect positive linear correlation. All points lie exactly on a straight line with positive slope, so \(x\) and \(y\) are redundant and one can be dropped during data reduction.

3 — Data Normalization

Scaling attribute values into a common range so that attributes with large magnitudes don't dominate. All four methods below are demonstrated on the same dataset.

Dataset used throughout \(\{200,\;300,\;400,\;600,\;1000\}\)

(a) Min-Max Normalization

Min-max $$v_i'=\frac{v_i-\min_A}{\max_A-\min_A}\big(\text{new\_max}_A-\text{new\_min}_A\big)+\text{new\_min}_A$$

Maps each value linearly into the range \([\text{new\_min},\,\text{new\_max}]\). Here we set new_min = 0, new_max = 1, with \(\min_A=200,\ \max_A=1000\) so \(\max_A-\min_A=800\).

Working

$$200'=\frac{200-200}{800}(1)+0=0$$

$$300'=\frac{300-200}{800}=\frac{100}{800}=0.125$$

$$400'=\frac{400-200}{800}=\frac{200}{800}=0.25$$

$$600'=\frac{600-200}{800}=\frac{400}{800}=0.5$$

$$1000'=\frac{1000-200}{800}=\frac{800}{800}=1$$

Result: \(\{0,\;0.125,\;0.25,\;0.5,\;1\}\)

(b) Z-Score Normalization

Z-score (using standard deviation) $$v_i'=\frac{v_i-\mu_A}{\sigma_A}\qquad \mu=\text{mean},\ \ \sigma=\text{std. deviation}$$
Step 1 · Mean

$$\mu=\frac{200+300+400+600+1000}{5}=\frac{2500}{5}=500$$

Step 2 · Standard deviation

$$\sigma=\sqrt{\tfrac15\big[(200{-}500)^2+(300{-}500)^2+(400{-}500)^2+(600{-}500)^2+(1000{-}500)^2\big]}$$

$$=\sqrt{\tfrac15(90000+40000+10000+10000+250000)}=\sqrt{\tfrac{400000}{5}}=\sqrt{80000}=282.84$$

Step 3 · Z-scores

$$200'=\frac{200-500}{282.84}=-1.06\quad 300'=\frac{-200}{282.84}=-0.707\quad 400'=\frac{-100}{282.84}=-0.35$$

$$600'=\frac{100}{282.84}=0.354\qquad 1000'=\frac{500}{282.84}=1.77$$

Result: \(\{-1.06,\;-0.707,\;-0.35,\;+0.354,\;+1.77\}\)

(c) Z-Score using Mean Absolute Deviation

A more robust version: replace \(\sigma\) with the mean absolute deviation \(s_A\), which is less sensitive to outliers because deviations are not squared.

Z-score with mean absolute deviation $$v_i'=\frac{v_i-\bar A}{s_A}\qquad s_A=\frac1n\big(|v_1-\bar A|+|v_2-\bar A|+\dots+|v_n-\bar A|\big)$$
Step 1 · Mean absolute deviation (mean \(\bar A=500\))

$$s_A=\frac15\big(|200{-}500|+|300{-}500|+|400{-}500|+|600{-}500|+|1000{-}500|\big)$$

$$=\frac15(300+200+100+100+500)=\frac{1200}{5}=240$$

Step 2 · Normalized values

$$200'=\frac{200-500}{240}=-1.25\quad 300'=\frac{-200}{240}=-0.833\quad 400'=\frac{-100}{240}=-0.417$$

$$600'=\frac{100}{240}=+0.417\qquad 1000'=\frac{500}{240}=+2.08$$

Result: \(\{-1.25,\;-0.833,\;-0.417,\;+0.417,\;+2.08\}\)

(d) Normalization by Decimal Scaling

Decimal scaling $$v_i'=\frac{v_i}{10^{\,j}}\qquad\text{where } j \text{ is the smallest integer such that } \max(|v_i'|)\le 1$$

The largest absolute value is 1000. We need \(10^{\,j}\ge 1000\), so \(j=3\) (since \(10^3=1000\)). Divide every value by 1000.

Working (example check: if A ranged \(-986\) to \(917\), then \(986/1000=0.98\le1\Rightarrow j=3\))

$$200'=\tfrac{200}{10^3}=0.2\quad 300'=0.3\quad 400'=0.4\quad 600'=0.6\quad 1000'=1.0$$

Result: \(\{0.2,\;0.3,\;0.4,\;0.6,\;1.0\}\)

4 — Discretization & Binning

Partitioning continuous values into bins, then smoothing noisy data. Always sort the data first, then apply the technique.

Number of bins $$\text{number of bins}=\frac{\text{number of values}}{\text{frequency (values per bin)}}$$

Three smoothing techniques are covered: (a) equal-frequency binning, (b) smoothing by bin mean, (c) smoothing by bin boundary.

Unit · Association Rule / Pattern Mining

5 — FP-Growth & Frequent Patterns

FP-Growth finds frequent itemsets without generating candidates (unlike Apriori). It compresses the database into an FP-tree, then mines patterns recursively from it.

Support & confidence (the foundation)

Support of an itemset A $$\text{sup}(A)=\frac{\text{freq}(A)}{\text{number of transactions}}$$ Confidence of a rule A → B $$\text{Conf}(A\Rightarrow B)=\frac{\text{sup\_count}(A\cup B)}{\text{sup\_count}(A)}$$

Apriori — context & its limitations

Apriori mines frequent patterns by generating candidate \(k\)-itemsets level by level. Its weaknesses, and the improvements people use:

  • Hash-based technique — reduces the size of candidate \(k\)-itemsets \(C_k\).
  • Partitioning — partition the data; any itemset frequent overall must be frequent in at least one partition, so mine candidates per subset.
  • Sampling — mine on a representative subset of the data for speed.

Closed vs Maximal frequent itemsets

  • Closed itemset: an itemset is closed if none of its immediate supersets has the same support count as it.
  • Maximal frequent itemset: a frequent itemset that has no frequent superset.
Numerical · min support = 2

Given supports: \(A=3,\ B=3,\ C=3,\ AB=2,\ AC=2,\ BC=2,\ ABC=1\).

\(ABC=1 < 2\) → not frequent. So \(A,B,C\) are not maximal (each has a frequent 2-item superset).

Maximal frequent itemsets = {AB, AC, BC} — none of these has a frequent superset (their only superset \(ABC\) is infrequent).

Unit · Classification

6 — Decision Tree Classification

A greedy, top-down method (Hunt's algorithm). At each node we pick the attribute that produces the purest children. "Purity" is measured by an impurity index; the best split has the lowest impurity / highest gain.

Three impurity measures for a node \(t\)

Gini index — \(p_i(t)\) is the fraction of class \(i\) at node \(t\) $$\text{Gini}(t)=1-\sum_{i=0}^{c-1}\big[p_i(t)\big]^2$$ Entropy $$\text{Entropy}(t)=-\sum_{i=0}^{c-1}p_i(t)\,\log_2 p_i(t)$$ Misclassification error $$\text{Error}(t)=1-\max_i\big[p_i(t)\big]$$

Choosing the best split — the gain

Weighted impurity of children after a split (k children) $$M=\sum_{i=1}^{k}\frac{n_i}{n}\,\text{Impurity}(i)\qquad n_i=\text{records in child } i,\ n=\text{total}$$ Gain = (impurity of parent before split) − (weighted impurity of children) $$\text{Gain}=P-M$$
The decision rule — memorise this Compute \(M\) for every candidate attribute. The best split is the one with the smallest \(M\), which is the same as the largest Gain. A lower degree of impurity is always preferred.

Method B — Entropy & Information Gain

Notation note (log base) Standard entropy uses \(\log_2\). This worked solution (matching the source notes) evaluates the logs in base 10, so for a 50:50 split it gives \(0.3010\) instead of \(1.0\). Because changing the log base just multiplies every entropy by the same constant, the ranking of attributes (and the chosen root) is identical either way. Numbers below are base-10 to match what you'll likely see in class.
Parent entropy

$$\text{Entropy}(P)=-\big[\tfrac{10}{20}\log(\tfrac{10}{20})+\tfrac{10}{20}\log(\tfrac{10}{20})\big]=0.3010$$

Gender → \(M_1\)

$$E(N11)=-\big[\tfrac6{10}\log\tfrac6{10}+\tfrac4{10}\log\tfrac4{10}\big]=0.2922,\quad E(N12)=0.2922$$

$$M_1=\tfrac{10}{20}(0.2922)+\tfrac{10}{20}(0.2922)=0.2922$$

Car Type → \(M_2\)

$$E(N21)=-\big[\tfrac14\log\tfrac14+\tfrac34\log\tfrac34\big]=0.244$$

$$E(N22)=0\ (\text{pure}),\qquad E(N23)=-\big[\tfrac18\log\tfrac18+\tfrac78\log\tfrac78\big]=0.1636$$

$$M_2=\tfrac4{20}(0.244)+\tfrac8{20}(0)+\tfrac8{20}(0.1636)=0.0488+0+0.0654=0.11424$$

Shirt Size → \(M_3\)

$$E(N31)=0.2922,\ \ E(N32)=0.2966,\ \ E(N33)=E(N34)=0.3010$$

Gender: \(0.3010-0.2922=\mathbf{0.0088}\)

Car Type: \(0.3010-0.11424=\mathbf{0.1868}\) ← largest

Shirt Size: \(0.3010-0.297225=\mathbf{0.0038}\)

Conclusion (both methods agree) Car Type gives the highest gain → it is selected as the root node. The tree then recurses on each child (the Sports child is already pure → a leaf labelled C0).

Advantages & disadvantages of decision trees

Advantages: inexpensive to construct; easy to interpret for small trees; robust to noise; extremely fast at classifying unknown records; handle redundant and irrelevant attributes well.

Disadvantages: each decision boundary involves only a single attribute (axis-parallel splits); the greedy nature can cause sub-optimal choices ("favouritism").

Unit · Prediction (Supervised)

7 — Linear Regression

A supervised method that fits a straight line \(y=w_0+w_1x\) to numeric data for future prediction. \(w_0\) is the intercept and \(w_1\) is the slope.

General form For multiple inputs: \(y(x,w)=w_0+w_1x_1+w_2x_2+\dots+w_nx_n\), or using basis functions \(y(x,w)=w_0+\sum_{i=1}^{m}w_i\phi_i(x)\). Common basis/learning functions include the Gaussian \(\phi_j(x)=e^{-(x-\mu)^2/2\sigma^2}\), the sigmoid \(\sigma(x)=\tfrac1{1+e^{-x}}\), and \(\tanh(x)=2\sigma(x)-1\).

Least-squares estimates

Slope $$w_1=\frac{N\sum xy-(\sum x)(\sum y)}{N\sum x^2-(\sum x)^2}$$ Intercept $$w_0=\frac{\sum y-w_1\sum x}{N}\qquad N=\text{number of data points}$$
Numerical
\(x\)6061626365
\(y\)3.13.63.84.04.1
Step 1 · Sums (N = 5)

$$\sum x=311,\quad \sum y=18.6,\quad \sum xy=1159.7$$

$$\sum x^2=60^2+61^2+62^2+63^2+65^2=19359$$

Step 2 · Slope and intercept

$$w_1=\frac{5(1159.7)-(311)(18.6)}{5(19359)-311^2}=\frac{5798.5-5784.6}{96795-96721}=\frac{13.9}{74}\approx 0.187$$

$$w_0=\frac{18.6-0.187(311)}{5}=\frac{18.6-58.16}{5}\approx -7.911$$

Regression line: \(\;y=-7.911+0.187\,x\)

Step 3 · Predictions (estimated y)

$$\hat y(60)=3.3,\ \ \hat y(61)=3.496,\ \ \hat y(62)=3.684,\ \ \hat y(63)=3.871,\ \ \hat y(65)=4.245$$

Residual (standard) error

Residual error — spread of actual values around the fitted line $$\varepsilon=\sqrt{\frac{\sum (y-\hat y)^2}{n-2}}$$
Working

$$\sum(y-\hat y)^2=(3.1{-}3.3)^2+(3.6{-}3.496)^2+(3.8{-}3.684)^2+(4{-}3.871)^2+(4.1{-}4.245)^2$$

$$=0.04+0.0108+0.0135+0.0166+0.0210\approx 0.103$$

$$\varepsilon=\sqrt{\frac{0.103}{5-2}}=\sqrt{0.03433}=0.185$$

What \(\varepsilon\) tells you \(\varepsilon=0.185\) is the typical gap between observed and predicted \(y\). The notes illustrate this by writing \(y=w_0+w_1x-\varepsilon\): e.g. for the first point \(3.3-0.185=3.11\approx 3.1\), recovering the original observed value. Small \(\varepsilon\) ⇒ the line fits well.

8 — Logistic Regression

Used for classification (not prediction of a continuous value). It feeds a linear combination through the sigmoid, producing an output between 0 and 1 that is read as a probability.

Sigmoid & hypothesis function

Sigmoid $$\sigma(x)=\frac{1}{1+e^{-x}}$$ Hypothesis for two features $$h_\theta(x)=\sigma(b_0+b_1x_1+b_2x_2)=\frac{1}{1+e^{-(b_0+b_1x_1+b_2x_2)}}$$
Decision rule (threshold = 0.5) If \(h_\theta(x)\ge 0.5\Rightarrow y=1\) (e.g. malignant / cancer). If \(h_\theta(x)<0.5\Rightarrow y=0\) (benign / non-cancer).

Training by gradient descent

Weight update rule (per feature, α = learning rate) $$b=b+\alpha\,(y-y_{pred})\,y_{pred}\,(1-y_{pred})\,x$$
Numerical · tumour data, α = 0.3
tumour size \(x_1\)2.71.43.33.065.3
tumour vol \(x_2\)2.52.34.43.052.75
class \(y\)00001
Record 1 · \(x_1=2.7,\ x_2=2.5,\ y=0\) — start with \(b_0=b_1=b_2=0\)

$$y_{pred}=\frac{1}{1+e^{-(0+0\cdot2.7+0\cdot2.5)}}=\frac{1}{1+e^{0}}=\frac12=0.5$$

$$b_0=0+0.3(0-0.5)(0.5)(1-0.5)(1)=0.3(-0.125)=-0.0375$$

$$b_1=0+0.3(0-0.5)(0.5)(0.5)(2.7)=-0.1012$$

$$b_2=0+0.3(0-0.5)(0.5)(0.5)(2.5)=-0.09375$$

After epoch 1 (record 1): \(b_0=-0.0375,\ b_1=-0.1012,\ b_2=-0.09375\)

Record 2 · \(x_1=1.4,\ x_2=2.3\) — predict with the updated weights

$$y_{pred}=\frac{1}{1+e^{-(-0.0375+(-0.101)(1.4)+(-0.09375)(2.3))}}=0.403$$

\(0.403 < 0.5\Rightarrow y=0\) — matches the true class, so the classification is correct.

Why this matters Linear regression predicts a continuous number; logistic regression squashes the line through the sigmoid to predict a class label. The same weight-update loop continues over all records and repeats for several epochs until the weights converge.
