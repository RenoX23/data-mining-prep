Course 
Description 
This course provides an understanding of basic fundamentals, methodologies 
and applications of data mining. It explores both supervised and unsupervised 
learning methods. Through practical applications, students will gain the 
knowledge to solve real world problems. 
Course 
Objectives 
(Optional) 
1. To gain a comprehensive understanding of data mining fundamentals and 
develop expertise in data preprocessing techniques. 
2. To explore and apply the supervised and unsupervised learning methods in 
data mining. 

--- PAGE 3 ---
 
 
 
 
 
3. To design and implement models for solving complex real-world problems 
effectively. 
Course Outcomes CO1: Explain the basic fundamentals of Data mining and how to preprocess 
the data. (L2) 
CO2: Apply appropriate association algorithm to mine frequent patterns.(L3) 
CO3: Apply classification and related data mining techniques accurately and 
efficiently using Python for computations.(L3) 
CO4: Apply clustering and related data mining techniques accurately and 
efficiently using Python for computations. (L3) 
CO5: Develop a model using appropriate algorithm to solve real world 
problems.(L3)
